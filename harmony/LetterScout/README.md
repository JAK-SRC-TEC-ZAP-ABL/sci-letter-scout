# SCI Letter Scout HarmonyOS App (development build)

Native ArkTS/ArkUI project for DevEco Studio 26.0.0. The current milestone builds a debug-signed HAP in the owner's DevEco project and displays the public paper feed. It is not a release-signed AppGallery package.

Implemented: first-run onboarding for oncology and 13 NLM-catalogued anesthesiology journals, all-versus-selected journal subscriptions within the chosen specialty, local persistence of subscription settings and favorites, paper list, search by title/journal/DOI, abstract/detail view with a tappable DOI/publisher link, manual refresh, explicit evidence disclaimer, network-error state, and a privacy-policy link. A 113-entry journal catalogue is bundled so specialty and journal selection remains available on first launch without network access. This catalogue is generated from `config/journals.json` by `scripts/generate_builtin_journals.ps1`; it is a candidate list and does not establish that every journal's ISSN or Letter policy has been verified. All matching papers are shown regardless of their reading-priority score. A dormant Push Kit listener remains in the project, but this version does not request notification consent or obtain a Push Token before registration and delivery are implemented. No Gemini key, ServerChan key or Huawei server credential is bundled. The specialty and journal choice filters the shared cloud feed on the device; it does not create a per-user cloud scan.

Not implemented yet: cloud-side per-user subscriptions, AI scheduled analysis, secure Push Token registration, the server-side Push API sender, in-app notification settings, release signing, physical-device Push testing, and AppGallery submission. AppGallery Connect Push Kit activation must be verified in the developer account. The journal selection currently filters only this device's public feed. Do not publish this milestone as a finished app.

Open this project from an ASCII-only path in DevEco Studio. The build tool rejects the Chinese characters in the parent workspace path. The bundle name `com.sciletterscout.app` matches the application registered in AppGallery Connect; use associated-app signing for this identity.

The feed URLs are defined in `entry/src/main/ets/pages/Index.ets`. Papers with a PubMed ID but no DOI can be displayed and saved. The app first tries the public GitHub Pages feed, then GitHub's raw file endpoint if the first request fails. GitHub Pages was verified in the emulator on 2026-11-03; a physical device has not been tested. The app saves the last successfully downloaded feed and journal catalogue locally and labels cached data and its generation time when a refresh fails. First use requires a reachable data source to display papers, while the bundled catalogue supports offline setup. Opening the app downloads the feed and catalogue; manually refreshing downloads the feed again. There is no client-side background polling. Production distribution needs an availability and privacy review.
